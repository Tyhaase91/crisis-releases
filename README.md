# C.R.I.S.I.S. Downloads

Public downloads and release notes for the Crawler Resource, Inventory & Status Information System.

[Download the latest release](https://github.com/Tyhaase91/crisis-releases/releases/latest)

Version 1.2.0 adds the Battle tab, release checking, level-collapse tracking, companion status details, inventory images, and usability fixes.

Choose **CRISIS-Setup-1.2.0.exe** for the Windows installer or **C.R.I.S.I.S-win32-x64-1.2.0.zip** for the portable app.

Create a **Complete ZIP Backup** before updating. Character JSON backups contain data only; complete ZIP backups include portraits and item images.

Source code is maintained separately in a private repository. This public repository contains downloads and release information.
